# Evidence

Evidence integra o Code Review e pode ficar no registro único da demanda. Relatórios separados são opcionais quando úteis; arquivos históricos permanecem preservados. Usar [contrato](../prompts/evidence.md), sem secrets/dados reais.

Expor checks/resultados reais, review independente, riscos, não verificados e decisões provisórias. READY TO SHIP é prontidão técnica, com aceite humano final/publicação separados; Done requer aceite final. Não duplicar comandos/logs entre registros.
