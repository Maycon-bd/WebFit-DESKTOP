# Regras de negócio

**Status:** catálogo vazio; regras candidatas permanecem nas fontes de descoberta.

Use `RN-<DOM>-NNN`. Cada regra deve declarar enunciado verificável, justificativa, condições, exceções, fonte, requisitos afetados, testes e status.

```text
ID:
Título:
Regra:
Justificativa:
Condições e exceções:
Fonte:
Requisitos relacionados:
Testes relacionados:
Status: proposto
```

Contradições conhecidas estão registradas no [log de decisões](../project/decision-log.md#decisões-pendentes). Não escolher uma variante silenciosamente.
