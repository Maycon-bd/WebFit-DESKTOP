# Fluxos de interação

**Status:** nenhum fluxo aprovado.

Para cada fluxo, registrar ator, objetivo, entrada, caminho principal, alternativas, erros, recuperação, estados vazios, autorização, auditoria e requisitos relacionados. A [primeira jornada candidata](../product/journeys.md) é o ponto inicial para validação, não um fluxo pronto para implementação.
