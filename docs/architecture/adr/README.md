# Registros de decisão arquitetural

ADRs registram contexto, opções, decisão, consequências e evidências. Status permitidos: `proposto`, `aceito`, `rejeitado`, `substituído` ou `descontinuado`. Uma proposta autorizada para spike não deve ser marcada como aceita antes dos critérios de validação.
