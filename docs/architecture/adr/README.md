# Registros de decisão arquitetural

ADRs registram contexto, opções, decisão, consequências e evidências. Status permitidos: `proposto`, `aceito`, `rejeitado`, `substituído` ou `descontinuado`. Uma proposta autorizada para spike não deve ser marcada como aceita antes dos critérios de validação.

- [ADR-0003 — Ativação offline e suporte por instalação](ADR-0003-ativacao-offline-e-suporte.md) — aceito por Maycon em 2026-10-08, após proposta v1/D-LIC-006..008 e aprovação da implementação.
- [ADR-0002 — Atualizações e distribuição do aplicativo](ADR-0002-atualizacoes-e-distribuicao.md) — proposto; decisão humana pendente.
