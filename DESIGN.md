# Interface de trabalho

Direção técnica provisória dentro da UX aprovada: aplicação de operação, sem telas promocionais. Barra lateral fixa para pacientes, perfil, auditoria e backup; conteúdo central com lista pesquisável ou formulário único. Fundo claro quente, texto escuro, verde escuro para ação primária, fonte Segoe UI nativa do Windows. Sem imagens externas ou dependência de rede. Ação principal evidente, erros junto ao formulário, preservação do texto digitado, confirmação de arquivamento/restauração. Não altera campos nem fluxos aprovados.
